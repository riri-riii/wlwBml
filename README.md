# wlwBml

Wonderland.NET向けの非公式ブックマークレットです。

## ブックマークレット

ブックマークのURL欄に以下を登録してください。

```javascript
javascript:(function(d){var a=d.createElement('script');a.src='https://cdn.jsdelivr.net/gh/riri-riii/wlwBml@main/wlw-bookmarklet.js';a.onload=function(){var b=d.createElement('script');b.src='https://cdn.jsdelivr.net/gh/riri-riii/wlwBml@main/wlw-export.js';d.body.appendChild(b)};d.body.appendChild(a)})(document)
```

## 初回設定

1. Wonderland.NETへログインする。
2. マイキャスト一覧のファイタータブ1ページ目を開く。
3. ブックマークレットを実行し、獲得済みキャスト一覧をlocalStorageへ保存する。

## 戦績取得

1. 任意のキャスト詳細ページを開く。
2. ブックマークレットを実行する。
3. 非表示iframeで全キャストの戦績を取得し、勝率などを計算する。キャストランクも同じページから取得する。
4. 取得結果はWonderland.NETオリジンのlocalStorageへ保存する。既存の戦績データ形式は維持し、ランクを`ranks`に追加する。

## 表示するキャストの選択

画像出力機能は廃止し、ページのキャスト別勝率の表示・非表示を選択する機能に置き換えました。

1. キャスト詳細ページを再読み込みし、ブックマークレットを実行する。
2. 全キャストの取得後、右下に表示される「キャスト選択」を押す。
3. 全キャストのチェックボックスから、表示したいキャストを選ぶ。
4. 「OK」を押すと、選択したキャストの勝率行だけが表示される。

初期状態は登録済みの全キャストを選択・表示します。0勝0敗の行も表示対象です。チェック操作だけではページ表示は変わりません。「キャンセル」で未確定の変更を破棄できます。

### まとめて選択するボタン

| 操作 | 動作 |
| --- | --- |
| 全選択 | すべてにチェックを付ける |
| 全解除 | すべてのチェックを外す |
| 指定勝数以上のみ | 入力した勝利数以上のキャストだけにチェックを付ける |
| 指定CR以上のみ | 入力したキャストランク以上のキャストだけにチェックを付ける |

条件ボタンはそれぞれチェック状態を置き換えます。勝利数とCRの両方を順に押してもAND条件にはなりません。条件で選んだ後に手動でチェックを調整し、OKで反映できます。

### 表示・保存について

- チェック欄にはキャスト名・勝利数・CRを表示する。
- ランクを取得できなかったキャストは`[不明]`と表示する。ランク条件からは除外するが、手動で選択できる。
- 絞り込み対象はキャスト別の勝率行のみ。現在開いているキャストの詳細戦績と「全キャスト勝率」の集計は変更しない。
- 選択状態はそのページを開いている間だけ保持し、ページ再読み込み後は全選択に戻る。
- 選択操作では追加通信や戦績データの書き換えを行わない。

## ファイル構成

- `wlw-bookmarklet.js`: キャスト一覧・戦績・ランク取得、勝率計算、localStorage保存、キャスト別勝率の表示
- `wlw-export.js`: キャスト表示選択UI。既存ブックマークとの互換性のためファイル名を維持しているが、画像生成機能は含まない
- `bookmarklet.txt`: ブックマークURL欄へ登録する短縮コード

## 注意

- SEGA公式ツールではありません。
- Wonderland.NET側のHTMLや挙動が変更された場合、動作しなくなる可能性があります。
- プライベートブラウズではlocalStorageが保持されない場合があります。
- jsDelivrのCDNキャッシュにより、`main`更新直後は古いJSが一時的に配信される場合があります。今回の更新は取得本体と選択UIの両方を読み直す必要があります。
- 勝率・敗北数の計算方法は従来どおりで、表示済みの平均値から求める推定値です。
