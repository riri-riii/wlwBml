# ロール絞り込み確認用

通常配布とは別の確認用ブランチです。mainとGitHub Pagesの公開版は変更していません。

## 操作確認

1. bookmarklet-role-preview_02.txtの1行をコピーし、「WLW確認用」などの別ブックマークのURL欄に登録します。
2. WONDER.NETのキャスト詳細ページを再読み込みし、確認用ブックマークを実行します。
3. 初回は「全キャスト取得」を選び、全員のロール情報を取得します。キャスト一覧登録済みなら一覧の再登録は不要です。
4. 「キャスト選択」を開いてCR条件とロール条件を変更します。
5. 通常版へ戻る場合はページを再読み込みし、従来のブックマークを実行します。

確認版は通常版と同じ戦績保存先を使用し、ロール情報を追加します。全キャスト取得は従来と同じく戦績を更新します。

## 仕様

- 1行目に全選択／全解除、2行目に等幅のCR・ロール選択を配置。
- ロールは全ロール／ファイター／アタッカー／サポーター。初期値は全ロール。
- CRとロールはAND条件。変更時は該当キャストだけ表示して全選択。
- カスタム時はランク不問でロール条件のみ適用し全解除。
- OKで確定、キャンセルで破棄。再表示では確定した条件とチェックを保持。
- ロール未取得は全ロールだけ対象。取得案内を表示。
- 詳細ページの.data_cast_roll imgからicon_role_0/1/2.pngを取得。
- 全キャストと現在キャストのみの両取得経路に対応。
